# Loom cinematic source

This source bundle contains the cinematic cloud/fog scrolling layer and supporting app files.

Expected assets:
- src/assets/clouds/cloud-01.png
- src/assets/clouds/cloud-02.png
- src/assets/clouds/cloud-03.png
- src/assets/clouds/cloud-04.png
- src/assets/fog/fog-01.png
- src/assets/fog/fog-02.png

The existing Navbar.jsx and your existing project assets are intentionally not replaced.
Copy these files into the matching locations in your Loom Vite project.

Required packages:
- @react-three/fiber
- @react-three/drei
- three
- gsap
- lenis
